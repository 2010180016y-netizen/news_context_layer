# News Context Public Contact Draft

Use this file as the source for the public contact route referenced by Chrome Web Store metadata.
The current alpha uses the public issue tracker as the contact channel linked from the hosted contact page.

## Public Contact

- Product: `News Context`
- Operator: `News Context operator, an independent software project`
- Contact: `https://github.com/2010180016y-netizen/news_context_layer/issues`

## What To Include In A Message
- article URL
- time of the issue
- current screen or state
- expected result
- actual result

## Inquiry Types
- product usage issue
- billing / Founder Pass issue
- parser or related-coverage quality issue
- privacy or legal inquiry

## Sensitive Requests
- Do not post sensitive personal information publicly.
- If a request needs private follow-up, ask for a private reply route in the issue and provide only the minimum identifying details needed.
