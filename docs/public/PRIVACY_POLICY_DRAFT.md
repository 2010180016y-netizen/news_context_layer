# News Context Privacy Policy Draft

This file is the current publishable source draft for the Chrome Web Store privacy policy URL.
It now assumes the public contact route is the hosted `public-contact.html` page plus the linked GitHub issue tracker.

## Privacy Policy

`News Context` helps users compare related news coverage for the article they are currently reading.

### Who operates this extension
- Operator: `News Context operator, an independent software project`
- Public contact page: `https://2010180016y-netizen.github.io/news_context_layer/public/public-contact.html`

### What the extension does
- Opens a side panel when the user clicks the extension action
- Reads the currently open supported article page only when the user actively invokes the extension
- Sends a limited set of article metadata to the backend so related coverage can be found
- Lets the user save watchlists, view briefings, and manage preferences

### Data we process
Depending on the feature used, the extension may process:

- article URL or canonical URL
- article title
- publisher name
- author names
- published or modified timestamps
- article section
- keywords
- a short body excerpt used for comparison
- parse confidence and related matching signals
- anonymous device identifiers
- watchlist and plan state
- optional analytics events only when the user opts in

### Data we do not use for advertising
- We do not use article data or usage data for targeted advertising.
- We do not sell personal information.

### Analytics
- Analytics is optional and opt-in.
- If enabled, analytics is used to improve product quality and reliability.
- If disabled, analytics events are not sent.

### Local storage
The extension stores limited local state in the browser, such as:
- onboarding completion
- analytics preference
- anonymous device identifiers
- latest panel context
- checkout return state

### Support and operational contact
The public contact page links to the project's public issue tracker for product, billing, parser-quality, and privacy inquiries.

### Data retention
Operational data should be retained only as long as reasonably needed for alpha support, debugging, abuse prevention, and legal obligations. Deletion or privacy review requests should be routed through the public contact page with the minimum details needed to identify the request.

### Your choices
Users can:
- choose whether to opt in to analytics
- stop using the extension at any time
- contact the operator using the public contact route listed above

### Changes
This policy may be updated as the product evolves. Material changes should be reflected in the published policy page and related consent/version records.
