News Context Public Contact

This is the public contact route for the current alpha. It is suitable for the Chrome Web Store public contact field and for product, billing, parser-quality, and privacy inquiries.

Operator

Operator: News Context operator, an independent software project.

Public issue tracker: https://github.com/2010180016y-netizen/news_context_layer/issues

How to contact the operator

Use the public issue tracker above for general product questions, Founder Pass problems, parser or quality issues, and privacy or legal requests. If your request involves sensitive information, do not post the sensitive details publicly. Instead, share only the minimum context needed and ask for a private follow-up route.

What to include in a message

  • article URL
  • time of the issue
  • current screen or state
  • expected result
  • actual result

Inquiry types

  • product usage issue
  • billing or Founder Pass issue
  • parser or related-coverage quality issue
  • privacy or legal inquiry

Deletion and privacy requests

If you are making a deletion or privacy request, include the minimum details needed to identify the request, such as the article URL, approximate date, and anonymous device identifier if available.

Response expectation

Alpha support is handled on a best-effort basis. Critical product and privacy inquiries are reviewed as soon as practical, but a public issue tracker should not be treated as an emergency channel.
