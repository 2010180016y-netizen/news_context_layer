# 11. 오픈 이슈 및 의사결정 로그

## 1. 목적
이 문서는 개발 착수 전에 다시 논의하지 않을 결정과, 아직 열어 둬야 하는 항목을 구분해 기록한다. 개발 착수 기준의 최종 잠금 문서는 `docs/DECISION_LOCK.md`다.

## 2. 개발 착수 기준으로 잠금된 결정
### 제품 범위 / 비범위
- v1 개발 착수 범위는 네이버 뉴스 데스크톱 기사 페이지 대상의 `Chrome MV3 + Side Panel` 경험으로 고정한다.
- 현재 단계 구현 범위는 기사 파싱, 출처 카드, 같은 이슈 비교, 최신성 경고, 공통 신호, watchlist 1개 저장, 피드백, 익명 analytics opt-in까지만 포함한다.
- 판정 기능, 정치 성향/언론사 스코어링, 유튜브/소셜, 모바일, LLM 요약, 정기결제, API 판매, 다중 watchlist, 이메일 브리핑, paywall, 기본 계정 시스템은 현재 단계 비범위로 고정한다.

### 결제 시점
- Founder Pass 1회 결제와 paywall은 `Gate 3 유료 베타`에서만 도입한다.
- 즉 `Week 11-12` 이전의 개발 착수 범위에는 결제 구현을 넣지 않는다.
- 결제 형태는 1회 결제를 우선하고 정기결제는 후속 단계에서 검토한다.

### auth 방식
- Gate 2 개발 착수 기준 auth는 `디바이스 기반 익명 식별 only`로 잠근다.
- `anon_id`와 디바이스 기반 `X-User-Token`을 기준으로 watchlist, consent, analytics, feedback를 연결한다.
- 이메일 계정, magic link, 소셜 로그인은 현재 단계 범위에서 제외한다.

### summary / 알림 / 데이터 소스
- `summary_line`은 `OG description 우선 + 규칙 압축 fallback`으로 고정한다.
- 알림은 현재 단계에서 구현하지 않으며, 실제 발송이 시작되는 첫 방식은 `이메일 브리핑 우선`으로 고정한다.
- 데이터 소스 우선순위는 `RSS -> sitemap -> 공개 메타데이터 -> Naver Search API fallback`으로 고정한다.

### 플랫폼 / 정책
- Chrome MV3, Side Panel, `activeTab` 클릭 실행, 원격 코드 금지, analytics opt-in은 다시 열지 않는 전제 조건으로 고정한다.

## 3. Gate 이후 결정
### A. 결제 provider
상태:
- Gate 이후 결정

선택지:
- 네이버페이
- 카카오페이
- 토스페이먼츠
- Paddle

결정 필요 시점:
- Week 9 이전, Gate 3 준비 시작 전

판단 기준:
- 베타 구현 난이도
- 국내 전환율
- 환불/재결제 처리 편의성

### B. 이메일 등록 / magic link 도입 여부
상태:
- Gate 이후 결정

현재 잠금 기준:
- 개발 착수는 디바이스 기반 익명 식별만으로 시작한다.

후속 선택지:
- 디바이스 기반 only 유지
- 이메일 magic link 도입
- 소셜 로그인 도입

결정 필요 시점:
- 결제 복구, 기기 간 동기화, 브리핑 구독이 실제 요구되는 Gate 3 설계 시점

### C. embedding 생성 방식
상태:
- Gate 이후 결정

선택지:
- 외부 API 사용
- 경량 오픈모델 자체 실행
- embedding 없이 rules 중심 유지

현재 기준:
- 알파는 rules 중심으로 시작하고, 정확도 미달일 때만 external embedding을 재검토한다.

### D. 브라우저 푸시 알림 도입 여부
상태:
- Gate 이후 결정

현재 잠금 기준:
- 초기 알림 방식은 이메일 브리핑 우선
- 브라우저 푸시/실시간 알림은 현재 단계와 Gate 3 초기 범위에서 제외

### E. 향후 확장 전략
1. 네이버 뉴스 외 다음/개별 언론사 읽기 표면 확장은 언제 하는가?
2. 유튜브 뉴스 지원은 v2.5 또는 v3 중 어디에 넣는가?
3. B2B 샘플 리포트 템플릿은 산업별로 나눌 것인가?
4. Analyst 플랜에서 CSV export가 정말 강한 전환 트리거인가?
5. 장기적으로 provenance/C2PA 신호를 언제 결합할 것인가?
