# 01. PRD — 뉴스컨텍스트

## 1. 문서 목적
이 문서는 뉴스컨텍스트 v1의 제품 범위, 사용자 문제, 성공 기준, 핵심 기능, 비기능 요구사항을 정의한다. 이 문서를 기준으로 PM, 개발, 디자인, QA, 운영이 같은 제품을 바라보도록 한다.

---

## 2. 제품 개요
### 제품명
뉴스컨텍스트 (가칭)

### 제품 한 줄 설명
**현재 읽고 있는 뉴스 기사 옆에서 같은 이슈의 다른 기사, 출처 정보, 최신성 경고를 보여주는 Chrome 사이드패널 확장프로그램**

### 제품 철학
이 제품은 기사의 진위를 판정하지 않는다. 대신 사용자가 한 기사만 보고 성급히 판단하지 않도록, **비교 가능한 맥락과 신호**를 제공한다.

### 금지 포지셔닝
- 가짜뉴스 판별기
- 진실 점수 앱
- 언론사 랭킹 앱
- 정치 성향 분류기

---

## 3. 배경 문제
사용자는 포털과 커뮤니티에서 자극적인 기사를 자주 접하지만, 같은 이슈를 다른 기사와 비교하려면 탭을 여러 개 열고 검색해야 한다. 이 과정은 번거롭고, 대부분의 사용자는 결국 기사 한 개만 보고 판단한다.

### 현재 불편
1. **검색 비용** — 같은 이슈 기사 찾기가 귀찮다.
2. **출처 맥락 부족** — 기자명, 수정시각, 기사 유형을 잘 보지 않는다.
3. **최신성 문제** — 오래된 기사인지, 이미 업데이트된 이슈인지 모른다.
4. **비교 피로** — 기사 여러 개를 보더라도 핵심 공통점을 빠르게 뽑기 어렵다.

---

## 4. 목표
### 비즈니스 목표
- 12주 내 Public Beta 출시
- 베타 기간 내 Founder Pass 유료 검증
- v1.5에서 watchlist/브리핑 PMF 검증
- 6개월 내 Starter Report 판매 기반 마련

### 사용자 목표
- 기사 하나만 보고 판단하지 않도록 돕는다.
- 10초 안에 추가 맥락을 이해하게 한다.
- 관심 이슈를 지속적으로 추적할 수 있게 한다.

### 성공 목표
- 첫 사용자가 “아 이거 필요했다”를 즉시 느끼게 한다.
- 제품 신뢰를 해치지 않으면서 반복 사용을 만든다.

## 5. 타깃 사용자
### 1차 타깃
**포털·커뮤니티·유튜브에서 정치/경제/사회 뉴스를 자주 보는 25~44세 지식근로자**

#### 특징
- 브라우저 기반 소비가 많다.
- 새 뉴스 앱은 설치하지 않는다.
- “이 기사 말고 다른 곳은 어떻게 썼지?”를 자주 궁금해한다.
- 출근길/근무 중 짧은 시간에 빠르게 판단하려 한다.

### 2차 타깃
**PR / IR / 정책 / 리서치 / 브랜드 세이프티 담당자**

#### 특징
- 특정 이슈의 보도 방향을 계속 봐야 한다.
- 기사 정확성보다 커버리지 차이와 맥락이 중요하다.
- 알림, 브리핑, 리포트에 비용을 지불할 가능성이 있다.

## 8. 사용자 스토리
### 무료 사용자
- 내가 보고 있는 뉴스 기사가 오래된 건지 알고 싶다.
- 이 기사와 같은 이슈를 다룬 다른 기사 3개 이상을 보고 싶다.
- 기자명/수정시각/기사 유형을 한 번에 보고 싶다.
- 관심 있는 이슈 1개를 저장하고 싶다.

### 유료 후보 사용자
- 특정 이슈를 저장해 두고 새 기사나 업데이트가 나오면 받고 싶다.
- 저장한 이슈를 나중에 다시 보고 싶다.
- 아침에 오늘 볼 이슈를 빠르게 요약받고 싶다.

### B2B 후보 사용자
- 특정 기업/정책/이슈에 대해 매체별 커버리지 차이를 정기적으로 보고 싶다.
- 같은 이슈에서 어떤 키워드와 숫자가 반복되는지 보고 싶다.
- 보도량 급증이나 프레임 변화를 빨리 감지하고 싶다.

## 9. 기능 정의
### 기능 1. 현재 기사 파싱
설명: 현재 탭의 기사에서 제목, 언론사, 기자명, 발행/수정 시각, 기사 유형, 요약 가능한 단서를 추출한다.

### 기능 2. 출처 카드
설명: 기사 출처 관련 핵심 정보를 구조적으로 보여준다.

### 기능 3. 같은 이슈 기사 비교
설명: 현재 기사와 유사도가 높은 기사 3~5개를 보여준다.

### 기능 4. 최신성/업데이트 경고
설명: 더 최신 기사가 존재하거나 기사가 수정된 경우 경고를 표시한다.

### 기능 5. 공통 신호 스트립
설명: 상위 관련 기사들에서 반복적으로 등장하는 핵심 개체명/숫자/날짜를 보여준다.

### 기능 6. watchlist 저장
설명: 현재 이슈(cluster)를 저장한다.

### 기능 7. 피드백
설명: 관련도, 유용성, 버그 등 피드백을 받는다.

## 10. 상세 요구사항
### 기능 1. 현재 기사 파싱
#### 입력
- URL
- DOM
- JSON-LD
- meta tags

#### 출력
- `title`
- `publisher_name`
- `author_names[]`
- `published_at`
- `modified_at`
- `article_type`
- `section`
- `keywords[]`
- `body_excerpt`
- `parse_confidence`

#### 수용 기준
- 지원 URL 샘플 300개 기준 파싱 성공률 90% 이상
- 필수 필드 확보율 85% 이상

### 기능 2. 출처 카드
#### 표시 항목
- 언론사명
- 기자명
- 발행 시각
- 수정 시각
- 기사 유형 배지

#### 수용 기준
- 메타데이터 누락률 10% 이하

### 기능 3. 같은 이슈 기사 비교
#### 표시 규칙
- 3~5개 기사 카드 노출
- 카드 정보: 언론사, 발행 시각, 제목, 1줄 요약
- 충분한 결과가 없으면 “관련 기사를 충분히 찾지 못함” 표시

#### 수용 기준
- top-5 관련 기사 precision 80% 이상
- p95 컨텍스트 로드 2.5초 미만

### 기능 4. 최신성/업데이트 경고
#### 상태
- Fresh
- Watch newer
- Updated
- Older context

#### 수용 기준
- 사용자 “도움 됨” 응답 60% 이상

### 기능 5. 공통 신호 스트립
#### 예시
- 공통 언급: 산업부 / 반도체 / 수출규제
- 공통 수치: 15% / 2026년 3분기

#### 수용 기준
- 상위 기사 5개 기준 핵심 신호 3초 이내 표시

### 기능 6. watchlist 저장
#### 정책
- Free는 1개 저장
- 중복 cluster 저장 불가

#### 수용 기준
- 활성 사용자 중 watchlist 저장률 15% 이상

### 기능 7. 피드백
#### 수집 유형
- 도움 됨
- 관련도 낮음
- 더 최신 기사 원함
- 버그
- 자유 의견

#### 수용 기준
- 활성 사용자 10% 이상 피드백 참여

## 11. 비기능 요구사항
### 성능
- 패널 최초 렌더 p95 < 1.0초
- 컨텍스트 응답 p95 < 2.5초
- 백엔드 API 오류율 < 1%

### 안정성
- 수집 실패 시 캐시된 최근 결과 반환 가능
- low-confidence 상태 명시
- 지원하지 않는 페이지 graceful fail

### 보안
- `activeTab` 기반 동작
- 상시 브라우징 감시 금지
- 원격 코드 금지
- 민감 정보 저장 금지

### 프라이버시
- 익명 사용통계 opt-in
- 전송 데이터 최소화
- 브라우징 데이터 광고 활용 금지

### 접근성
- 키보드 탭 이동 지원
- 기본 색 대비 확보
- 폰트 14px 이상

## 13. 가설과 검증 포인트
### 가설 1
사용자는 판정이 아니라 비교/출처/최신성만으로도 만족한다.

### 가설 2
“이 이슈 저장”과 알림은 강한 유료 전환 트리거가 된다.

### 가설 3
같은 이슈 기사 비교만으로도 커뮤니티에서 설치를 유도할 수 있다.

### 가설 4
네이버 뉴스 페이지 하나에 집중해도 초기 PMF 검증은 가능하다.

---

## 14. 리스크
### 리스크 1
비교만 보여주면 오히려 혼란이 커질 수 있다.

대응:
- 공통 신호 스트립
- 최신성 경고
- low-confidence 표기

### 리스크 2
네이버 UI 구조 변경으로 파서가 깨질 수 있다.

대응:
- JSON-LD → meta → DOM fallback
- 샘플 URL 회귀 테스트

### 리스크 3
권한/프라이버시 불신으로 설치 전환이 떨어질 수 있다.

대응:
- 클릭형 작동 명시
- 수집 항목 설명 UI
- 과도한 권한 배제

## 15. 출시 판단 기준
### Go
- parser success ≥ 90%
- top-5 precision ≥ 80%
- D1 ≥ 40%
- D7 ≥ 25%
- watchlist ≥ 15%

- paywall 관심도 낮음
