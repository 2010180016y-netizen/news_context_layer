## 8. 베타 랜딩 / 세일즈
### Hero
- 헤드라인: 지금 읽는 기사에서, 같은 이슈의 다른 보도를 바로 비교
- 서브헤드라인: 페이지를 떠나지 않고 출처, 최신성, 공통 신호를 10초 안에 확인합니다.
- Primary CTA: 지금 기사 비교해보기
- Secondary CTA: 샘플 리포트 보기

### 즉시 가치
- 현재 기사 옆에서 같은 이슈 기사 3~5개를 바로 비교합니다.
- 언론사, 기자, 발행·수정 시각을 한 번에 보여줍니다.
- 더 최신 기사나 수정 여부를 신호로 알려줍니다.

### 반복 사용 가치
- 관심 이슈를 watchlist로 저장해 다시 돌아올 이유를 만듭니다.
- daily briefing은 반복 확인 흐름의 scaffold이며, 실제 발송은 Gate 이후 범위입니다.

### Founder Pass 이유
- Founder Pass는 더 많은 watchlist 저장과 briefing 접근을 여는 베타 업그레이드입니다.
- 개인 사용자가 이슈를 계속 추적할 이유를 만드는 옵션으로 설명합니다.

### B2B Starter Report
- starter report는 팀 대시보드 대신 파일 형태로 coverage 차이와 공통 신호를 보여주는 초기 제안 자료입니다.
- sample issue report, daily briefing scaffold, JSON/CSV export를 함께 보여줄 수 있습니다.

### 금지 문구 / 범위 가드레일
- external API 판매를 약속하지 않는다.
- team dashboard를 이미 제공하는 것처럼 말하지 않는다.
- 월 정기구독을 beta 범위처럼 말하지 않는다.
- 기사의 진위를 판정하거나 언론사 점수를 매긴다고 말하지 않는다.
