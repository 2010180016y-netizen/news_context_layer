# B2B Talk Track

## 30초 요약
- 뉴스컨텍스트는 기사의 진위를 판정하지 않습니다.
- 대신 지금 읽는 기사에서 같은 이슈의 다른 보도, 출처 맥락, 최신성 신호를 바로 비교하게 해 줍니다.
- 그 비교를 watchlist와 daily briefing scaffold로 반복 사용 흐름에 연결하고, B2B에서는 sample issue report와 JSON/CSV export로 전달형 파일럿을 시작합니다.

## 5분 미팅 흐름
### 1. 첫 화면
- "사용자는 지금 읽는 기사 하나에서 출발합니다."
- "페이지를 떠나지 않고 관련 보도 3~5개, 출처, 최신성 신호를 바로 확인합니다."

### 2. 반복 사용으로 연결
- "한 번 보고 끝나는 도구가 아니라, watchlist와 briefing으로 다시 돌아올 이유를 만듭니다."
- "Founder Pass는 이 반복 사용을 여는 개인용 업그레이드입니다."

### 3. B2B 데모 가치
- "팀 대시보드가 없어도, sample issue report와 briefing scaffold로 coverage 차이와 공통 신호를 바로 보여줄 수 있습니다."
- "초기 파일럿은 report delivery 자산으로 검증합니다."

### 4. 안전한 범위 설명
- "beta에서는 external API 판매, team dashboard, 월 정기구독을 약속하지 않습니다."
- "지금은 실제로 보여줄 수 있는 비교 경험, 저장, briefing scaffold, export handoff까지만 설명합니다."

## 자주 쓰는 한 줄
- "한 기사만 보고 판단하지 않게 돕는 비교 레이어입니다."
- "지금 기사 비교의 즉시 가치와, 다음 날 다시 돌아오게 만드는 반복 사용 구조를 함께 보여줍니다."
- "Starter Report는 대시보드 대신 파일 형태로 B2B 대화를 시작하는 베타 자산입니다."

## 말하지 말아야 할 것
- "API로 바로 붙일 수 있습니다."
- "팀 대시보드가 이미 있습니다."
- "월 구독 플랜이 준비돼 있습니다."
- "진실 여부를 판정해 줍니다."
