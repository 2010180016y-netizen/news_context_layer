# Landing Copy Assets

## 목적
- beta 운영과 세일즈 대화에서 같은 메시지를 반복해도 충돌하지 않도록 카피 축을 고정한다.
- 현재 실제로 보여줄 수 있는 기능만 말하고, Gate 이후 범위는 명시적으로 분리한다.

## Message Pillars
### 1. 기사 비교의 즉시 가치
- 헤드라인: 지금 읽는 기사에서, 같은 이슈의 다른 보도를 바로 비교
- 서브헤드라인: 페이지를 떠나지 않고 출처, 최신성, 공통 신호를 10초 안에 확인합니다.
- 증거 문구:
  - 현재 기사 옆에서 같은 이슈 기사 3~5개를 바로 비교합니다.
  - 언론사, 기자, 발행·수정 시각을 한 번에 보여줍니다.
  - 더 최신 기사나 수정 여부를 신호로 알려줍니다.

### 2. watchlist / briefing의 반복 사용 가치
- 헤드라인: 한 번의 비교를 반복 확인 습관으로
- 본문: watchlist와 daily briefing scaffold는 지금 본 이슈를 나중에도 다시 확인할 이유를 만듭니다.
- 증거 문구:
  - Free는 watchlist 1개 저장
  - Founder Pass는 더 많은 watchlist와 briefing 접근
  - daily briefing은 반복 사용 구조를 보여주는 scaffold이며, 실제 발송은 아직 beta 범위가 아님

### 3. Founder Pass 업그레이드 이유
- 헤드라인: 더 오래 추적하려면 Founder Pass
- 본문: 한 번의 기사 비교를 저장과 briefing 접근으로 이어, 개인 사용자가 계속 돌아오게 만드는 베타 업그레이드입니다.
- CTA:
  - Founder Pass 열기
  - 업그레이드하기
- 보조 문구:
  - 결제 후 기능이 바로 활성화됩니다.
  - beta에서는 월 정기구독과 팀 플랜을 약속하지 않습니다.

### 4. B2B Starter Report의 데모 가치
- 헤드라인: 대시보드 없이도 시작할 수 있는 Starter Report
- 본문: sample issue report, daily briefing scaffold, JSON/CSV export로 특정 이슈의 coverage 차이와 공통 신호를 파일 형태로 보여줍니다.
- 증거 문구:
  - 내부 데이터 기반 sample issue report 1건 제공 가능
  - cluster 기반 daily briefing scaffold 제공 가능
  - JSON/CSV export 경로 정의 완료

## Trust / Safety Copy
- 이 도구는 기사의 진위를 판정하지 않습니다.
- 여러 출처의 관련 보도를 비교할 수 있게 정리해 사용자의 판단을 돕습니다.
- analytics는 동의한 사용자에게만 적용됩니다.

## CTA Set
- Primary: 지금 기사 비교해보기
- Secondary: 샘플 리포트 보기
- Founder Pass: Founder Pass 열기
- B2B: Starter Report 예시 보기

## Scope Guardrails
- external API 판매를 약속하지 않는다.
- team dashboard를 이미 제공하는 것처럼 말하지 않는다.
- 월 정기구독을 beta 범위처럼 말하지 않는다.
- 이메일 briefing 실제 발송을 이미 제공한다고 말하지 않는다.

## Gate After
- SEO용 장문 카피
- 월 정기구독 카피
- team / analyst 플랜 상세 메시지
