# B2B Starter Pack Draft

## Purpose
- Gate 4 탐색 전, beta 운영 상태에서 실제로 보여줄 수 있는 자료만 묶는다.
- 팀 대시보드나 external API보다 먼저, report delivery 자산으로 문제 공감과 파일럿 가능성을 검증한다.

## Included Assets
- sample issue report
- cluster 기반 daily briefing scaffold
- landing copy 핵심 문구
- support/contact 운영 플로우
- JSON/CSV export 경로

## Core Story
1. 현재 기사 비교의 즉시 가치
2. watchlist / briefing으로 이어지는 반복 사용 구조
3. Founder Pass가 개인 반복 사용을 여는 이유
4. Starter Report가 대시보드 없이도 B2B 대화를 시작하게 해 주는 이유

## Recommended Meeting Flow
1. extension에서 현재 기사와 관련 기사 비교 화면을 먼저 보여준다.
2. sample issue report로 같은 이슈를 파일 형태로 정리해 전달할 수 있음을 설명한다.
3. daily briefing scaffold로 “다음 날에도 왜 다시 보게 되는가”를 설명한다.
4. Founder Pass는 개인 사용의 업그레이드 흐름으로만 설명하고, 팀 요금제처럼 확장하지 않는다.
5. CSV/JSON export는 pilot handoff 초안으로만 설명하고, entitlement나 API 판매처럼 말하지 않는다.

## Draft Delivery Paths
- Sample issue report JSON: `infra/exports/reports/sample-issue-report.json`
- Sample issue report CSV: `infra/exports/reports/sample-issue-report.csv`
- Daily briefing scaffold JSON: `infra/exports/briefings/daily-briefing-sample.json`
- Starter pack JSON: `infra/exports/b2b/starter-pack-sample.json`
- Starter pack CSV: `infra/exports/b2b/starter-pack-sample.csv`

## Safe Talking Points
- "지금 읽는 기사 하나에서 같은 이슈의 다른 보도를 바로 비교할 수 있습니다."
- "watchlist와 daily briefing scaffold가 반복 사용 이유를 만듭니다."
- "Founder Pass는 더 많은 저장과 briefing 접근을 여는 베타 업그레이드입니다."
- "초기 B2B는 team dashboard보다 report delivery 자산으로 먼저 검증합니다."

## Explicit Non-Scope
- external API 판매
- team dashboard 제공
- 월 정기구독 / seat 관리
- 맞춤형 analyst workflow 확정
